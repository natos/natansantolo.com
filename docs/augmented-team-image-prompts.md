# Image Generation Prompts for "The Augmented Team"

Based on a comprehensive analysis of the book's seven chapters, here are recommended prompts for generating illustrations that capture the key themes and concepts. Each prompt is designed to be used with AI image generation tools like Midjourney, DALL-E, or Stable Diffusion.

---

## Style Guidelines for All Images

**Color Palette:**
- Primary: Deep purple (#7C3AED), Cyan (#06B6D4)
- Accents: White, Light gray
- Background: Dark gradients (midnight blue to deep purple to black)
- Highlights: Neon glows in purple/cyan

**Visual Style:**
- Modern, clean, tech-forward
- Glassmorphic elements where appropriate
- Isometric views for system/organizational concepts
- Intimate portraits for emotional/human moments
- Network visualizations for interconnected systems
- Avoid literal representations - embrace metaphor and abstraction
- Balance sophistication with approachability

**Common Elements:**
- AI assistants represented as holographic/glowing presences
- Code represented with clean, readable syntax highlighting
- Design artifacts (Figma frames, tokens, components) as floating UI elements
- Human figures should show emotion and personality, not just be icons
- Light = knowledge, confidence, capability
- Connections = collaboration, infrastructure, multiplication

**Mood:**
- Aspirational but grounded
- Technical but human
- Challenging but achievable
- Individual growth within collective transformation

---

## Implementation Notes

1. **Consistency:** Use similar visual language across all images - same color palette, similar geometric style, consistent icon system

2. **Progression:** Images should show evolution and growth, not static states

3. **Balance:** Mix abstract conceptual images with more concrete, relatable scenes

4. **Emotion:** Don't lose the human element - this is a story about people learning and growing

5. **Technical authenticity:** When showing code, terminals, or tools, use realistic details (real command syntax, authentic git workflows, actual VS Code interface elements)

6. **Accessibility:** Ensure sufficient contrast, don't rely solely on color to convey meaning, consider how images read in grayscale

## Alternative Prompt Styles

For different tools or aesthetic preferences, here are alternative prompt frameworks:

### For Midjourney:
Add: `--ar 16:9 --style raw --v 6` for most images
Add: `--ar 3:4 --style raw --v 6` for portrait-oriented images
Add: `cinematic lighting, professional color grading, high detail`

### For DALL-E 3:
Focus on: clear composition, specific colors, "professional illustration style"
Avoid: overly complex layering, too many simultaneous concepts

### For Stable Diffusion:
Add: Style tags like `(concept art:1.2), (professional illustration:1.3), (clean geometric shapes:1.1)`
Use: Negative prompts for `blurry, low quality, messy, cluttered, amateur`
